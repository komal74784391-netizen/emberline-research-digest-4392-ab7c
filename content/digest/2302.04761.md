Toolformer shows that a language model can teach itself to decide when and how to query external tools such as calculators, search engines and translation systems. The method annotates a large text corpus with candidate API calls, then keeps only the annotations whose use reduces the model's perplexity on the surrounding tokens. With this self-supervised signal the model learns to insert calls into ordinary text without any human demonstration. The resulting model answers factual questions, performs arithmetic and translates phrases substantially better than its base counterpart, while retaining its general language ability on tasks that do not benefit from tools.
